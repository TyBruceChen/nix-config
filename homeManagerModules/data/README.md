## Zsh aliases

- `shelltree` (Linux): show the current shell's process ancestry with `pstree`.

- `core-keeper-id` (Linux): read the game ID from the `core-keeper` Docker container.

- `workF`: change to `~/Documents/codes/`.
- `osF`: change to `~/nix-config/` on macOS or `~/Documents/nix-config/` on Linux.
- `rebuild-nix`: switch Home Manager directly on macOS and WSL; use `rebuild.sh` on the other hosts. The script expects `NH_FLAKE` to be set.
